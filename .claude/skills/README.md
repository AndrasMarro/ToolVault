# Project skills

Design skills from [VibeCurb](https://github.com/Yu-369/VibeCurb) (MIT, see `VIBECURB-LICENSE`),
pinned at commit `c324ba7`. Claude Code loads them automatically from this folder.

- `visual-redesign` – non-destructive restyling of existing pages (used for the hub skin of
  FileFlip and Unit Converter: override stylesheet, JavaScript logic untouched)
- `awwwards-hero`, `awwwards-sections`, `awwwards-motion`, `pixel-perfect`,
  `imagegen-frontend`, `brandkit-gen` – further design pipelines

GitHub Pages (Jekyll) does not publish dot-folders, so these files are not part of the site.
